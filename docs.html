devtemDesign Documentation

One configuration schema. Infinite animated synthesis. devtemDesign is a lightweight page engine. Pass one config object and it builds a complete landing page with glass cards, ambient motion, reveal animations, a mobile drawer, pricing, FAQ and footer. Plain HTML, CSS and JS, no framework and no build step.

Version 0.1.0MIT license7 templates0 dependencies
See it running on the examples page, or open the live demo.

Installation

CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/devtemdesign@0.1.0/style.min.css">
<script src="https://cdn.jsdelivr.net/npm/devtemdesign@0.1.0/script.min.js"></script>

Pin a version in production. Dropping @0.1.0 always serves the latest release, which may change.

npm

npm i devtemdesign

Then load node_modules/devtemdesign/style.css and script.js with your own tags, or import the function: const devtemDesign = require("devtemdesign").

Icons

Font Awesome is optional. It is only needed for feature icons and footer social icons. The menu, checkmarks and accordions are pure CSS.

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css">

Quick start

<div id="app-root"></div>
<script>
  devtemDesign("app-root", {
    template: "cyber",
    logoName: "MyBrand",
    navLinks: ["Home", "Docs", "About"],
    heroTitleLine1: "Hello",
    heroTitleLine2: "World",
    primaryBtnText: "Get started",
    primaryBtnHref: "/signup"
  });
</script>

Every section except the hero is optional. A section renders only when its config key is present.

Text fields are inserted as HTML so you can add icons and markup. Only pass trusted content.

Stats

stats: [
  { value: "12k+",   label: "Developers" },
  { value: "99.9%",  label: "Uptime" },
  { value: "$1,200", label: "Saved per launch" }
]

Values count up the first time they scroll into view. Prefix, suffix, commas and decimals are preserved. Use statsId to change the anchor id (default stats). With reduced motion enabled, the final value shows immediately.

Pricing

Set pricingLabel, pricingTitle, pricingSub and a pricing array. Anchor #pricing.

yearlyBadge: "Save 20%",
pricing: [
  { tier: "Free", amount: "$0", desc: "For experiments.", features: ["All templates"], cta: "Start free", href: "/signup" },
  { tier: "Pro", amount: "$12", period: "/mo", yearly: { amount: "$115", period: "/yr" },
    featured: true, badge: "Most popular", features: ["Everything in Free", "Priority support"], cta: "Go Pro", href: "/pro" }
]
Plan fieldDescription
tier, amount, period, descName, price, suffix and one-line pitch.
featuresString list with checkmarks.
cta, hrefButton label and link.
featured, badgeHighlights the card with a ribbon.
yearlyOptional { amount, period }. A Monthly/Yearly toggle appears when any plan has it. Plans without it keep their price in both views.

FAQ and closing CTA

faq: [
  { q: "Do I need a build step?", a: "No. Two tags and one call." }
],
cta: { title: "Ready to build?", sub: "Free for open source.", text: "Read the docs", href: "/docs" }

FAQ items use native <details>, so they work with the keyboard and one stays open at a time. Heading keys: faqLabel, faqTitle, faqSub. Anchor #faq.

Footer

footer: {

Theme tokens

Override any token with the theme option. Tokens are CSS custom properties on :root, so you can also use them in your own CSS.

theme: { accent: "#ff4d6d", accent2: "#ffb703", "bg-deep": "#0b0710" }
TokenPurpose
--accent, --accent2, --accent3Brand colors and gradients.
--text, --mutedPrimary and secondary text.
--bg-deepPage background. Also the text color on filled buttons.
--glass-bg, --glass-border, --glass-blurCard surfaces.
--surface, --lineSubtle fills and dividers.
--orbAmbient orb opacity.

JavaScript API

const page = devtemDesign("app-root", config);

page.setTemplate("sunset");   // switch theme without re-rendering
page.destroy();               // remove listeners, observers and markup

devtemDesign.version;         // "0.1.0"
devtemDesign.templates;       // ["figsh", "cyber", "aurora", ...]

Calling devtemDesign() again on the same container destroys the previous instance first, so there are no leaked listeners. It returns null if the container id is not found.

Accessibility

  • Skip link, visible focus rings and a labelled menu button with aria-expanded.
  • The active nav link gets aria-current.
  • prefers-reduced-motion turns off orbs, cursor, reveals, count-ups and smooth scroll.
  • Hover-only effects run only on devices that support hover.

Browser support

Current Chrome, Edge, Firefox and Safari. Theming uses color-mix(), which needs Chrome 111+, Safari 16.2+ or Firefox 113+. Older browsers still render the page but lose some tinted surfaces. Internet Explorer is not supported.

FAQ

Does devtemDesign need a build step?

No. Add one stylesheet and one script tag, then call devtemDesign() with a config object.

Can I change the colors of a template?

Yes. Pass a theme object such as { accent: "#ff4d6d" } to override any token.

Can I switch templates at runtime?

Yes. devtemDesign() returns an object with setTemplate(name), so the theme changes without re-rendering.
